# Company Blog

A blog listing application built with Next.js 14 as part of a frontend assignment.

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Server Components only

## Features
- Blog listing page with 3 posts per row
- Dynamic blog detail page (`/blog/[blogId]`)
- Pagination
- Sticky header
- Clean API wrapper pattern

## Getting Started

npm install
npm run dev
